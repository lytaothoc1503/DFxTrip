# Symphony Sea / VinaStay

Dự án đặt phòng mẫu và vé Dinner Show Sun Bavaria.

Mở trong Cursor:
1. Đăng nhập GitHub tài khoản lytaothoc1503.
2. Clone repo này vào workspace `symphony-sea`.
3. Phần giao diện đang chạy trên bản xem trước. Kho này giữ công thức giá và dữ liệu để sửa tiếp.

Giá phòng là dữ liệu mẫu. Vé và phụ thu bàn sát biển chưa trừ tiền thật.
